# 📦 Amazon Sales Dashboard

This interactive dashboard allows users to explore and analyze Amazon sales data, including:
- KPI overview (Total Sales, Number of Orders, Average Ticket)
- Monthly sales trends
- Order status distribution
- Top product categories by revenue

Built with **Python**, **Pandas**, **Matplotlib**, and **Streamlit**.

## 📊 Features
| Feature | Description |
|--------|-------------|
| **KPI Metrics** | Total sales, order count, average basket value |
| **Monthly Sales Chart** | Aggregated sales by month, automatically normalized |
| **Status Distribution** | Top status categories + automatic grouping into "Other" |
| **Top Categories** | Highest revenue product categories |

## 🛠️ Tech Stack
- Python 3.10+
- Pandas
- Matplotlib

- Streamlit
